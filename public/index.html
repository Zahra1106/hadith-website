الأمانة والتوثيق

Trust and verification, by design

Nothing is generated

Hadith text, translations and chain references are never written or altered by AI. Each entry is matched to its original wording in the source collection before it is published here.

Full attribution, always

Collection, book, chapter, Hadith number and grading are shown on every single Hadith — not just on a details page — so you always know exactly where a narration comes from.

AI, only as a librarian

Where smart search is used, it only helps locate existing, verified Hadith faster. It never composes religious content, and every result links back to its original reference.

How the content on this site is sourced: the homepage, topics, and Daily Hadith use a small, hand-checked set of well-known narrations, served instantly by the backend. The Full Library section calls a backend endpoint that downloads and caches the complete Arabic, English and Urdu text of a collection from the open-source Hadith API dataset (mirroring Sunnah.com), the first time it is requested. Nothing on this site is written or altered by AI. For research, legal rulings (fatwa), or academic citation, always verify wording and numbering against a printed critical edition or Sunnah.com, Dorar.net, or Islamweb directly.
